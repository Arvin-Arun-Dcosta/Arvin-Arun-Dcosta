## 👋 About Me

I'm a final-year Computer Science student at **VIT-AP** who builds full-stack web apps end to end: the UI, the API, the database and the deployment. Lately most of my time goes into **bringing AI into the web**: semantic search, embeddings running on my own server, and LLM features that stay optional, get validated and fail gracefully.

## 🧭 How I Build

- 🤖 **AI that earns its place:** semantic search with pgvector, small models running locally, and opt-in LLM features whose output is validated in code.
- ⚡ **Realtime that survives bad networks:** WebSockets with idempotent retries, offline queues and reconnect catch-up.
- 🔐 **Security from day one:** server-owned roles, session checks on every mutation, rate limiting and schema-validated input.
- 🧪 **Typed and tested end to end:** TypeScript and Zod from database to UI, with Vitest and Playwright running against a real Postgres.
- 📏 **Honest numbers:** benchmarks with their caveats, baselines to compare against and written-down dead ends.
